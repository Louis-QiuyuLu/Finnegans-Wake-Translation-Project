# 译注规范

## 先分清要保存什么

《守灵夜》的错拼、缀词、谐音与断句常有作用。不可先把英文改顺，再翻译改顺后的句子。正文尽量保留动作、节奏与歧义；注释补背景、证据和译法损失。

每段按三轮处理：第一轮听声音，圈出词形和重音；第二轮辨句法，列出可成立的读法；第三轮查来源，区分证据与猜测。完成初译后朗读中文，再删翻译腔。

## 中文

- 用「追问」「牵引」「回流」，少写「进行追问」「起到牵引作用」「发生回流」。
- 少用「的」。能写「河岸曲折」，便不堆成多层定语。
- 不用「最重要的……之一」这类松散判断；明确指出作用。
- 尽量写清动作发起者，减少无必要被动句。
- 删去「在某种意义上」「可以说」「具有……性」等空架子。
- 不机械添加复数后缀。
- 句长服从中文呼吸。Joyce 刻意连缀、停顿或重复，先记录作用，再选择补偿方式。

## 注释类别

`wordplay` 双关与词形；`culture` 人名、地名与习俗；`allusion` 典故；`sound` 声音与节奏；`structure` 前后照应；`syntax` 句法；`translation` 译法取舍。

`supported` 表示列出的来源支持此说，不表示作者意图已经坐实。`proposal` 表示本项目根据原文提出判断。`uncertain` 表示证据或上下文不足。

注释先交代可核实事实，再提出解释。不要列出一串语言便断言它们都藏在同一个词里。词源须有可靠词典、手稿或研究资料支持；检索不到便存疑。

## 审校状态

`draft` 试译；`revised` 修订待审；`reviewed` 已审校。人工审校者须核对底本、出处与中文，并在 `reviewers` 留名。自动检查只证明格式和链接符合规则，不能证明译义正确。

整章 `coverage` 独立于段落状态。录入全部正文并核对覆盖后，才能标 `complete`；`coverage_review` 写明核对者和依据。已经录入整章，也可能仍有待审段落。

## 异译

异译保存正文、取舍和署名。项目自产备选写明「本项目备选译法」；引用已有译本须列译者、版本、页码和出处，且只取比较所需范围。不凭记忆补写他人译文。
