# 底本与坐标

## 坐标不等于版本

工程采用通行的 **1939 年版分页及页行坐标**。`003.01–003.03` 表示第 3 页第 1 至第 3 行；这不是网页换行，也不是电子阅读器页码。

当前全章英文与稿段文字见证来自 [Faded Page 转录本](https://www.fadedpage.com/books/20180126/html.php)。其扉页列出 Viking Press 1958 年第八印本，注明已纳入作者勘误；不能笼统称为「1939 年初版逐字转录」。该站说明保留原书页行，调整部分行末连字符。

开篇另与 [FinnegansWiki 第 3 页](https://www.finnegansweb.com/wiki/index.php/Page_3) 对照。篇末以见证本第 628 页末两行定位，只收 A way 起的片段，未收入该行前半句。

## 版本差异

[JJDA](https://jjda.ie/f/fwhome.htm) 同时提供 1939、2010 年版及草稿资料。导读会列两套页码。引用前先确认页面当前显示哪一版；不能将 2010 年版默认文本当作 1939 年版。当前工程未做全书版本校勘。

后续若采用初版扫描件，登记扫描来源、刊本与页码，再逐段核对。更换见证本时保留差异说明，不静默覆盖旧稿。
