# 工程设计

## 目标

建立《芬尼根的守灵夜》中文译注工程。译者逐段录入底本、初译、修订和注释；读者可对照原文、查阅出处、比较异译。首版提供开篇与末句试译，全书其余部分明确标作待译。

## 取舍

参考 [QriDoki 的《追忆似水年华》工程](https://github.com/QriDoki/in-search-of-lost-time-translation-project)，沿用底本、初译、修订、润色、发布这条流程。

参考项目使用 VitePress 与 Pandoc，适合大量成熟稿件。本工程刚起步，采用 Python 3.9 以上版本及标准库，直接生成静态读本与 EPUB 3，免去额外安装。以后可更换阅读器，稿件格式不变。

## 稿件

- `manuscript/chapters/*.json` 是唯一编辑入口，覆盖四卷十七章。
- 每段固定 ID、页行范围、底本来源、初译、修订稿、审校状态。
- 注释记录词目、类别、正文、证据层级、来源 ID；异译独立保存。
- `raw-md/`、`translated-md/`、`polish/dev/`、`annotations/` 是自动生成的便读稿，不参与反向合并。
- 页码采用通行的 1939 年版分页。电子见证本与初版须分开标明。
- 章内有试译不代表整章完成，不计算虚假的全书完成百分比。

## 产物

- 静态网页：全书目录、双语对照、折叠注释、检索、术语表、明暗主题。
- EPUB 3：目录、双语正文、注释往返链接、来源表。
- Markdown：各阶段便读稿与进度清单。
- GitHub Actions：检查、构建、上传下载包；手动部署 GitHub Pages。

## 验收

检查重复 ID、空译文、页行越界、重复或倒置段落、悬空引文、无出处注释、审校状态失真。构建后检查站内锚点与 EPUB 内部链接。稿件中保留 Joyce 的断句、词形与回环；注释采用简洁中文，存疑解读须明说。
