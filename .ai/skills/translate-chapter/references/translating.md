# 译者工作法与损失记录

接初译或声形修订时读本文件。目标是交出可核对的译文与译注，不把多义词解成唯一答案。先辨声音、词形和局部句法，再选正文读路；不要先把英文改顺，再翻那个改顺版本。

## 从原文到正文

对照工作包，圈出否定、动作、连接、指代和句尾停顿。拼接词、错拼、重复、不完整句和大小写可能参与文义。保留原样核读；认为属于转录错误时交出处，不自行修正见证。

把难点分三层：原文可直接观察的形式；资料能支持的背景；本项目提出的解释。没有证据可以提出读法，不能编一条词源替它背书。段内关系不足时，正文避免补「因此」「原来」「他就是」等因果或身份结论。

原段有多条可成立读路，正文选能保留主要动作与节奏的一路，注释交待其他读法。不要把所有释义塞成括号串，也不要只留平顺单义释文。可保留原词、造短词、补声或给项目备选；选择须说清保留什么、丢失什么。不能为押韵添原文没有的事件。

## 声形损失怎样交接

在交接说明中按具体词句记录；若取舍影响读本理解，另写 `translation`、`sound` 或 `wordplay` 类注释。至少回答：

- **形式：** 实际拼写、重复音节、断句或字母组是什么；读音未查便写「待核」，不能把猜读标成标准发音。
- **读路：** 哪些义项可从上下文或已核资料成立；哪些只属音近、形近联想。
- **采用：** 正文哪几个字承接动作、声音、字形或语域；为什么不选另一方案。
- **损失：** 中文舍掉哪层双关、语音、节奏或版面关系；是否由注释或异译补偿。

例如，现有 `riverrun` 译名可沿用本段已核约定；若改「河水流」，须连读篇末再看开篇，不单论三个字是否顺口。该例只说明核对范围，不把暂定译法升为全书定译。雷鸣词可保留原拼并记录声效；未逐语核验的拆词不能凑成已证实语言清单。

## 何时调用研究

先在包内找证据。需要外查且结论会改变译义或注释时，交 [joyce-research](../../joyce-research/SKILL.md) 一条有边界的问题：词句、页行、候选读法、尚缺证据、需要决定的译法。以下情况常需研究：

- 混合词拆法牵涉具体语言、词源或地名，现有来源没有支持；
- 引用作者书信、笔记或其他作品解释此处，而只见转述或相似字眼；
- 英、中、日研究对同一处给出不同判断，且取舍会改变正文；其他语言按实际词源再查；
- 拟把多个 HCE／ALP 变体归为同一身份，或把跨段形式相似升成叙事关系。

普通词义已有可靠来源、旧术语在本段适用、只剩同义措辞，便不启动跨作品研究。新检索可先只查最能回答问题的一语；有分歧、遗漏或跨语转述时再用其他语言核查。研究检验特定主张，不给每段机械搜齐三语资料。

读回交稿时，分别看 `claim`、`evidence`、`interpretation`、`translation_impact`。直接证据支持原句或历史事实，不自动支持作者意图；研究者提出的译法不是定稿。打不开原页、只能看书目或社区转录时，写明查阅限度，择保守译法，留 `proposal` 或 `uncertain`。

## 中文修订

依余光中《中文的常态》读中文：用实义动词替换「进行」「具有」「起到」等空架子；拆连串「的」；不用「之一」凑判断；减少无须交代的被动；删「可以说」「在某种意义上」；不机械添「们」。分句先找动作，再看呼吸和句尾落点。

短句不等于齐整短句。Joyce 刻意连缀、迟疑、重复或不收尾时，在中文保留相应节奏，并在交接说明记代价。自检处理翻译腔，不把诡异词形、粗俗语气和含混修辞统统润成雅顺散文。古语、俗语或造词须由本段语域支持，不能凭「文学性」添饰。

## 初译与定点修订交付

初译 JSON 只含正式段落字段，每项承接工作包。`notes[].source_ids` 须指向已有来源；需新增来源，交整合者核登记后再合段。注释分类与证据层级按项目规范；引既有中译须有实际核过的译者、版本、页码和出处，不凭记忆补引文。

交接说明列输入指纹、采用读路、声形损失、真实查阅范围、未决事项及待增术语。`alternatives` 保存值得比较的完整译句、理由与真实署名；自产方案写「本项目备选译法」。不为每句凑备选。

审校意见按问题编号回应。初译之后最多两轮定点修订；每轮只改相应句注，说明「问题 → 采用或未采用 → 理由 → 当前稿路径」。改变正文含义、注释论据或术语范围时，提交该处复核。第二轮后若还漏译或证据伪造，交未完成稿并指出缺口；不能宣称「已收敛」。只剩偏好或明示的解释分歧，保留方案并交付，不在同义词间往返。
