# 导入与校勘

## 先选最少损耗的入口

可核版本的 HTML 已够用时，直接核 HTML；不用为了复刻参考流程再下载 EPUB、安装 Calibre 或 Pandoc。用户提供 EPUB、PDF 或扫描件时，先查版本、目录和阅读顺序，再决定抽取工具。文件类型不是底本质量等级。

临时解包、OCR 与整书缓存留在临时目录；只将本轮核过的短段和来源信息合入工程。转换成功只说明取到了文本，不能宣称已经校勘。

## EPUB

1. 找 `META-INF/container.xml` 指向的 OPF。依 manifest 和 spine 确定阅读顺序，目录只作辅助；不要按压缩包文件名排序。
2. 辨认封面、扉页、版权页、正文、插图及注释。首文件和末文件可能有正文，不能按位置排除。目录标题也不能当成正文小标题。
3. 查看章节链接、原页标记和注释回链。若缺通行页行，先对照可核见证再定位；电子阅读器的页码不写进 `range`。
4. 转换后核段界、斜体等强调、希腊字、爱尔兰语重音、字母符号与长词。图形、谱例、边注先登记，不能套用「全部删图」。
5. 多文件或单文件转换都可作中间稿；最后仍提交完整 JSON 段落，不直接发布转换 Markdown。

## HTML

区分正文与导航、网页注解、弹窗或后加超链接。带注释的社区正文须分别核文字见证和释义，不能把注解自动拼入 `original`。

保持自然段顺序。网页每行、浏览器视觉折行、原书行号可能不同；若仅有网页文本，没有扫描或可靠原排转录，页行须待核。跨页段落要联读两页，不能漏掉页首续词。

## PDF、扫描与 OCR

先看页面图像，再读抽取文本。OCR 常混淆 `rn/m`、`I/l/1`、撇号、重音和罕见字；《守灵夜》异常词尤其不能靠词典纠正。逐项对照实际稿段，不用抽样准确率保证未看的页面。

双栏、页边注与脚注可有独立阅读顺序。II.2 等章节的旁注和字母／图形关系须另拟保留办法。先用小范围验证当前构建能否表现，再扩录；格式缺失时保留问题与原页位置，不悄悄改成普通段落。

## 校勘的边界

初版、作者勘误、后期印本、编辑修订版和草稿各有身份。主稿沿当前见证；其他版本用于比较。若一处新版读法更易解释，也不能据此认定旧版是错字。作者书信自释若针对早稿，注明日期和稿态，不移作所有后期文本的唯一解释。

本项目没有全书校勘本。单段查过几个见证，就只报告该段对照范围。需要换底本时，先列影响的原文、页行、注释、锚句和版本记录，再统一处理。
