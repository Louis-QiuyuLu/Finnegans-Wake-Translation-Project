# 底本交接约定

## 坐标、文字见证与版次

章号、页行和见证本是三件事。通行 1939 年分页只提供定位，不证明文字来自初版。每批注明刊本、印次、转录者或机构、URL、访问日期及实际核过范围。网页标称版本与扉页不符时，保留差异，先核再选。

本项目当前使用 Faded Page 的 Viking 1958 年第八印本转录。其说明调整部分排版连字符；FinnegansWiki 可辅核原排行数，属于社区转录。两站相同只能说明两个见证相符，不能声称已看纸本。JJDA 引文须确认页面当前选用 1939 或 2010 年文本。

新增来源先拟完整 `sources/catalog.json` 条目：稳定 ID、标题、具体 URL、类型、访问日期、版本及用途。每条 `use` 只记本轮实际读过的材料。目录页、搜索结果、摘要、全文与扫描页须区别，不以站点声望代替查阅。

## 原文处理

1. 从当前断点锚句定位自然段，核对前段尾句与后段首句。先确定范围，再抽取。
2. 抽取后逐字比对大小写、重音、撇号、标点、连写、空格与异常拼写。保留 Joyce 错拼，不用拼写检查器自动修正。
3. 页面换行可以并为空格；排版断字是否并合须依据见证和上下文。词内连字符、雷鸣词及跨页长词逐项检查，不能统一删除连字符。
4. 页码、页眉和脚注标号先识别身份，再处理。引文中真实数字、符号、字母图形不当作页面垃圾删除。
5. 中文录入页行用通行坐标，原文不沿浏览器折行。段落范围为闭区间；同一行含多个短句时不造重叠范围。

特殊段落无法用现有 schema 保存时，先写格式问题及最小样例。当前 HTML 对原文转义，不能把任意标签塞进 `original` 期待它自动排版。技术格式尚未支持也不等于可以删正文。

## 差异记录

每项异文至少记：位置、见证 A、见证 B、差异类别、当前采用、理由与待核项。只摘所需短句，不保存整部外部电子书。

- 排版差异：行末断字、空白或字体；不能改变词义便说明合并方式。
- 转录疑误：OCR 或键入可能有误，但未见扫描前只称疑误。
- 作者修订／编者改订：须有版本或手稿证据，不把所有不同都算作者改稿。
- 解释差异：同一词的不同释义写研究问题，不能拿解释替换原字。

纠错不抹去旧记录。已经发布的原文若更正，报告保留旧字、新字、依据和受影响译注，交审校重新核该处。

## 工作包验收

`original` 不空，起止与 `range` 相符，`source_id` 已存在或有待合并来源条目，前段 ID 可定位，`next_original` 能在所选底本找到。`baseline` 固定的是输入文件版本；新增来源或术语交整合者合并，不让多个角色同时改公共表。

包中 `questions` 写明确问题，例如「否定词管到哪一从句」「此词的 Latin 读法据哪部词典」，不写「请深入研究」。每项给出已知与未知，说明会影响正文、注释还是备选译法。

`research_decision.required=false` 须说明本批没有新增指认或重大歧义，不表示全书不存在疑难。正文确定但解释未决时，可交合格来源包，译者保留歧义；正文残缺或坐标不清时，关口不通过。

## 最小交接

向译者交工作包、前后相邻段和相关术语；向研究者另交具体问题、候选读法和可访问证据。不要每次发送整部小说、全书术语表和所有报告。回复交文件路径、范围、已核与未核即可；是否通过由整合者核定。
