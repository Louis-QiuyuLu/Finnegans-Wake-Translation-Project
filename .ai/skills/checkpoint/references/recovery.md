# 恢复约定

## 启动核对

按顺序读主断点、当前章末段、相关工作包和交接记录；再查远端是否更新。一个文件存在不等于阶段完成，修改时间也不是版本依据。

确认四件事：主断点指向哪段；该段是否已经完整合入；初译和审校分别针对哪个版本；下一步缺的是原文、证据、译文、审校、生成还是同步。只恢复缺失阶段，不从头重跑。

## 中断场景

| 现状 | 恢复动作 | 主断点 |
| --- | --- | --- |
| 只有研究问题，尚无底本包 | 回到原句核版本、范围和下一锚句 | 留段首 |
| 底本包已核，研究未完 | 复用原文；只续未决问题，记录有限结论 | 留段首 |
| 初译文件只有半段 | 保留半稿，标最后核对锚句；补齐后才交审校 | 留段首 |
| 完整初译已交，未审校 | 比对原文包与输入版本，直接进入审校 | 留段首 |
| 审校后原文或译名改变 | 列差异，重核受影响结论；无关意见可保留 | 留段首 |
| 章稿已合入，断点未更新 | 核重复、缺口与段界，补断点，不再插入同 ID | 核完才前移 |
| 章稿与断点一致，生成稿旧 | 运行生成和检查，不重译 | 保持 |
| 本地已检查，远端未同步 | 读远端、合并差异，按同步技能发布 | 保持真实范围 |
| 远端已更新，页面仍旧 | 查构建与部署；报告部署中或失败 | 不回退已译范围 |

若断点反而落在已经合入的段内，先查是否此前保存失败、重排范围或误插重复稿。不得简单删除旧段来配合新断点。

## 主断点记录

`chapter` 是顺序续译章，不取样稿所在最末章。`next` 是下一个未完整合入段的起始页行；`next_original` 足以辨认该处，保留原字形。`updated` 用本轮真实日期。

`notes` 保存：连续完成范围；未决问题；所需来源或版本；半稿与报告路径；下一轮先做什么。旧问题解决后可简述依据并指向报告，再移出待办，不能因换了一轮便丢弃。

主断点不承载整份研究报告。已经有稳定报告路径时，写一句问题摘要和链接即可。上下文不足时优先保存可恢复工作，再结束；不要为了凑整页快速略译。

## 章节上下文摘要

`reports/context/I-1.md` 等文件包含：

1. 日期、已合入连续范围与下一段。
2. 本章确实出现过的人物、称谓、地点、字母变体及声音关系；说明哪些只是候选。
3. 本轮暂定译词、适用位置与不能外推之处，链接术语增量。
4. 研究与审校的关键取舍、来源入口和未决项。
5. 工作包、交稿、审校报告路径及下次恢复动作。

摘要不能把尚未读到的全书情节写成上下文事实。进入新章时只带相关信息；全书术语表和所有旧报告无需每批全读。

## 全章验收

逐段对照指定见证，检查首行、末行、跨页续词、段落顺序、特殊排版、脚注或正文附属材料。只凭坐标不重叠，无法证明没有漏段。`coverage_review` 写核对者、版本、范围、方法和未解决缺口；仍有正文缺口便不标 `complete`。

生成的章节记录是章稿投影，不是额外独立验收证据。全章完成后才能把主断点移到下一章；人工审校仍按段分别记录。

## 含远段样稿的章

当前校验器按目标章的最后一段比较断点，不区分连续前缀与远段样稿。IV 已有 628.15–628.16 样稿，真实顺序进入 IV 的 `[593,1]` 会因此报错。到该处前，须先扩断点校验，使它正确区分顺序稿与样稿，并用此实际场景验证，再切章。

不能把断点移到 628 页之后来躲过错误，不能删除篇末样稿，也不能把回环首句伪作下一锚句。本轮技能记录限制，不改现有工具；当前 I.1 续译不受此限制影响。

## 全书终点的兼容限制

当前 `checkpoint.json` 与校验器尚无 `terminal` 状态，仍要求章内下一坐标和非空锚句。真正译到 IV 最后一段时，先改断点格式、校验器和生成器，并用真实末段场景验证，再记录全书终结。本轮技能没有替工具实现该能力。不能编造末行之后的锚句，不能把 IV 的篇末样稿视作全书顺序译完。
