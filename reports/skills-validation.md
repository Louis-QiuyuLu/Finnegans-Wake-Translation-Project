## 独立场景走查

另一执行者按下列输入推演技能路径，检查下一动作、交付位置与禁止越过的关口。以下属于协议走查，不是已运行后台调度器或真实批量翻译的证明。

| 场景 | 验收结果 |
| --- | --- |
| 只取得论文摘要或题录 | 分记 `abstract_read`／`metadata_read`，结论不超出实际阅读范围 |
| 三语中某语正文不可得 | 留检索范围、访问障碍和下一入口；不凑引文，不声称该语没有研究 |
| 两处仅声形相似 | 先记相似事实；传播路径、借用和作者意图另立主张 |
| v1 审校晚到，当前已是 v2 | 保留旧报告，核差异并复核受影响范围；旧报告不替新稿背书 |
| 只更新交接状态 | 只改批次记录，冻结工作包和所审输入不变 |
| HCE／Howth 并发术语增量 | 逐词条、逐字段三方合并；保留无关更新，同字段冲突单列 |
| 完整初译已在，章稿尚未合入 | 核输入后复用交稿接审校；主断点留段首，不重复插段 |
| 同步前远端出现新提交 | 重读、合并、重核受影响判断，再绑定最新提交更新；不强推 |
| 全书末段没有真实下一锚句 | 先扩格式和工具再记录终结，不伪造锚句 |

查出并修正两项合同冲突：验收关口与持久阶段原先混名；可变状态原先放在冻结工作包。现在统一批次阶段枚举，发布另记，状态不回写输入包。

## 三语研究案例抽查

研究技能含 004.02 蛙声的有限案例，比较原句、古典剧作、中文译者访谈及日文资料缺口。独立核过 [Johnston《蛙》合唱局部](https://web.viu.ca/johnstoi/aristophanes/frogs.htm)、[台湾师范大学访谈报道](https://pr.ntnu.edu.tw/ntnunews/index.php?id=23740&mode=data&type_id=155) 和 [大阪大学 OUKA 摘要 PDF](https://ir.library.osaka-u.ac.jp/repo/ouka/all/81966/31641_Abstract.pdf)。

Johnston 页面是现代英译，不能冒充直接校读希腊原文或 Joyce 所据版本；访谈不能冒充译本原页；OUKA 文件是摘要，不能冒充论文正文。案例如实保留中日相关全文未得的范围，不把入口核验说成穷尽研究。

## 现有工具限制

工作记录仍靠整合者验收，`project.py` 不调度角色、不读取研究报告，也不判断释义正确或正文连续覆盖。

按当前 I.1 的真实断点可以使用本套技能。模板与协议通过核查，不等于自动翻译、学术结论或人工审校已经完成。
