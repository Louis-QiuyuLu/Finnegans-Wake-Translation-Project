# II.1 水手再登场与合唱

本轮核 II.1 232.27–234.36，归 `fw-ii1-231-01`。将所录英文与 Faded Page HTML 对读，核水手装、三问和报曲号等词形，并核 235.01 拜功接缝。章稿原文、坐标、初译与录音索引沿用原记录。

- 水手重返时保留舱底、打嗝和风暴。墙上挂像、报上登照出自角色夸口。保留 `can / now` 的语词替换。
- 三答逐次加一音节，译「瑙、瑙嗬、瑙嗬嗬」。三问先保留音形，供后续核三色复奏。

- 连祷里的「舔名」仍接亲吻；二十九照录为赞歌曲号，待核具体曲目。
- 合唱末尾跨页才接 `their salat`。前段留「她们念起」，次段以「拜功」续句。礼拜时辰留待下一轮。
