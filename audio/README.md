## 继续生成

生成语音另需完整的 GPT-SoVITS v4 环境及其预训练组件、PyTorch、NumPy、SoundFile，以及支持 `libmp3lame` 的 FFmpeg。它们不属于读本构建所需的 Python 标准库环境。

工具放在 `tools/gpt_sovits`，模型默认放 `models/Vertin`，也可用 `--model-dir` 指定**绝对路径**。脚本按所选变体检查两份权重。

脚本默认选 `sisyphus`，按 `Vertin-Sisyphus-v95.ckpt` → `Vertin-Sisyphus-e9.ckpt` → `Vertin-e10.ckpt` 回退，声学权重仍为 `Vertin_e2_s154_l32.pth`。默认参考为 `references/sisyphus2.wav`，不是仓库自带资源；缺少该录音时可回退至 `e1.wav`。除 `e3` 可用内置提示词外，其他参考录音须配同名且非空的 `.txt`。

若已备好原版 Vertin 权重及 `references/e1.wav`、`references/e1.txt`，可显式运行：

```bash
python3 scripts/generate_audio.py --model-dir /path/to/model --model vertin --ref e1 --segment fw-i1-007-16 --force
```

`--segment` 须指向公共章稿中实际存在的段落。只有清单指纹与现稿相符、MP3 存在且非空，脚本才跳过。旧指纹、空文件和未登记文件须重生；`--force` 会重生指定录音。脚本先写临时 WAV 和 MP3，再原子替换正式 MP3；登记时加锁，保留其他记录。合成后若原文已改，脚本中止登记，保留原录音。MP3 与清单各自原子替换，并非跨文件事务；中途断电后须重查指纹与文件。原文更改后须重新生成，不能只换清单指纹。

合成默认 `--speed 1.05 --steps 32`；网页默认播放1×是另一项设置。脚本先按意群合成，再经滤镜与响度处理转成192kbps MP3；参数不代表音质已获验证。`scripts/joyce_phonetics.py` 保存合成试验的发音近似方案，修改后须实听，不能当作已核定的语音词典。
