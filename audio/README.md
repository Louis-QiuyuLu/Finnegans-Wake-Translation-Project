## 继续生成

既有本机环境需提供 `tools/gpt_sovits`、模型和参考音频，模型默认放 `models/Vertin`，也可用参数指定：

```bash
python3 scripts/generate_audio.py --model-dir /path/to/model --segment fw-i1-007-16 --force
```

成功生成后，脚本登记该段原文与文件，保留其他记录。原文更改后须重新生成，不能只换清单指纹。`scripts/joyce_phonetics.py` 保存合成试验的发音近似方案；修改后须实听，不能当作已经外证核定的语音词典。
